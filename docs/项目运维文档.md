# 丹智慧眼 项目运维文档

---

## 一、系统概述

丹智慧眼是一个基于 AI 的眼镜推荐平台，由三个独立服务组成：

| 服务 | 框架 | 默认端口 | 说明 |
|------|------|----------|------|
| 前端 | 静态文件 (HTML/JS/CSS) | 5500 (Live Server) | 用户交互界面 |
| 后端 | Flask | 5000 | 业务逻辑、数据库操作 |
| 模型API | FastAPI | 8000 | 脸型识别、眼镜推荐 |

## 四、首次部署

### 4.1 克隆项目

```bash
git clone <仓库地址>
cd 丹智慧眼项目
```

### 4.2 创建虚拟环境

```bash
python -m venv .venv

# Windows (PowerShell)
.venv\Scripts\Activate.ps1

# Windows (CMD)
.venv\Scripts\activate.bat

# Linux/macOS
source .venv/bin/activate
```

### 4.3 安装后端依赖

```bash
pip install -r backend/requirements.txt
```

### 4.4 安装模型服务依赖

```bash
pip install fastapi uvicorn torch torchvision joblib numpy opencv-python pillow facenet-pytorch pandas scikit-learn pydantic
```

### 4.5 准备数据

1. 将眼镜商品数据放入 `data/glasses_data.csv`（UTF-8 或 GBK 编码）
2. 确保 `data/face/` 下有四个脸型子目录，各有对应人脸图片

### 4.6 训练模型（首次部署必须执行）

```bash
python model_train.py
```

执行后会在 `model/` 目录生成：
- `face_shape_model.pth` — 脸型识别模型
- `recommend_model.pkl` — 推荐模型
- `label_encoder.pkl` — 标签编码器

## 五、启动服务

需按以下顺序依次启动：

### 第一步：启动模型API服务（端口 8000）

```bash
# 默认端口 8000，可通过环境变量修改
# $env:MODEL_PORT=8001  (PowerShell)
python model_api.py
```

验证：
```bash
curl http://localhost:8000/docs
```

### 第二步：启动后端服务（端口 5000）

```bash
# 默认端口 5000，可通过环境变量修改
# $env:BACKEND_PORT=5001  (PowerShell)
python backend/backend_main.py
```

首次启动会自动创建 SQLite 数据库并从 CSV 导入眼镜数据。

验证：
```bash
curl http://localhost:5000/api/glasses/detail?glasses_id=pdd_1
```

### 第三步：启动前端

使用 VS Code Live Server 或任意静态文件服务器：

```bash
# 使用 Python 内置服务器
cd frontend
python -m http.server 5500
```

或直接用 VS Code 右键 `index.html` → "Open with Live Server"。

访问：`http://localhost:5500`

## 七、日常运维

### 7.1 启动服务（推荐顺序）

```bash
# 终端1：模型API
python model_api.py

# 终端2：后端
python backend/backend_main.py

# 终端3：前端（可选，也可用 VS Code Live Server）
cd frontend && python -m http.server 5500
```

### 7.2 停止服务

在各终端按 `Ctrl + C` 停止。

### 7.3 数据库管理

数据库文件位置：`data/backend.db`

```bash
# 备份数据库
copy data\backend.db data\backup\backend_$(Get-Date -Format "yyyyMMdd").db

# 查看数据库内容
sqlite3 data/backend.db ".tables"
sqlite3 data/backend.db "SELECT * FROM user;"
sqlite3 data/backend.db "SELECT COUNT(*) FROM glasses;"
```

### 7.4 更新眼镜数据

1. 编辑 `data/glasses_data.csv`
2. 删除旧数据库：`del data\backend.db`
3. 重启后端服务（会自动重新导入）

或通过 Python 手动重置：
```python
from backend.backend_main import app, db, Glasses
with app.app_context():
    Glasses.query.delete()
    db.session.commit()
    # 重启服务触发 init_db()
```

### 7.5 重新训练模型

数据更新后重新训练：
```bash
python model_train.py
```
重启模型API服务使新模型生效。

## 八、故障排查

### 8.1 前端无法连接后端

**现象**：浏览器控制台报 `Network Error` 或 `CORS error`

**排查**：
1. 确认后端是否启动：`curl http://localhost:5000/api/glasses/detail?glasses_id=pdd_1`
2. 检查 CORS 配置：`backend/backend_main.py` 中 `origins` 是否包含前端地址
3. 检查防火墙是否阻止了端口

### 8.2 模型API连接失败

**现象**：后端日志显示"模型服务连接失败"

**排查**：
1. 确认模型API服务已启动
2. 检查端口：`config.py` 中 `MODEL_API_URL` 与模型API实际端口一致
3. 确认模型文件存在：`model/face_shape_model.pth` 等

### 8.3 模型加载失败

**现象**：`RuntimeError: Error(s) in loading state_dict`

**排查**：
- `model_api.py` 和 `model_train.py` 中的模型结构必须一致
- 统一使用 `model_utils.py` 中的 `FaceShapeCNN` 类
- 如果更换了模型结构，需删除旧 `.pth` 文件后重新训练

### 8.4 数据库文件损坏

```bash
# 备份原文件后删除重建
move data\backend.db data\backend.db.bak
# 重启后端服务自动重建
python backend/backend_main.py
```

### 8.5 端口被占用

```bash
# Windows 查看端口占用
netstat -ano | findstr :5000

# 终止占用进程
taskkill /PID <进程ID> /F
```

## 九、性能优化建议

| 方向 | 建议 |
|------|------|
| 模型推理 | 启用 GPU (`torch.cuda.is_available()`)，推理速度提升 10-50 倍 |
| 并发处理 | 生产环境使用 `gunicorn` + `uvicorn workers` 替代 `python model_api.py` |
| 数据库 | 生产环境替换 SQLite 为 MySQL/PostgreSQL |
| 前端 | 压缩图片、启用浏览器缓存 |
| 部署 | 使用 Nginx 反向代理，统一端口入口 |

### 生产环境启动示例

```bash
# 模型API（4个 worker）
uvicorn model_api:app --host 0.0.0.0 --port 8000 --workers 4

# 后端（gunicorn）
gunicorn -w 4 -b 0.0.0.0:5000 backend.backend_main:app
```

## 十、安全注意事项

1. **生产环境关闭 debug 模式**：`app.run(debug=False)` 或设置环境变量 `FLASK_ENV=production`
2. **不要暴露数据库文件**：`data/backend.db` 不应在 Web 可访问路径下
3. **上传文件限制**：添加文件大小与类型校验
4. **API 限流**：建议添加请求频率限制防止滥用
5. **敏感信息**：数据库连接字符串等敏感配置通过环境变量注入，勿硬编码

## 十一、接口文档

### 后端接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/user/submit` | 提交用户图片和眼部参数，获取推荐 |
| GET | `/api/glasses/detail` | 查询眼镜详情 |

### 模型API接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/predict_face_shape` | 上传图片，返回脸型分类 |
| POST | `/get_recommendation` | 传入眼部参数和脸型，返回推荐眼镜列表 |

详细接口文档可访问：
- 后端：无自动文档（建议后续接入 Swagger）
- 模型API：`http://localhost:8000/docs` (FastAPI 自动生成)
