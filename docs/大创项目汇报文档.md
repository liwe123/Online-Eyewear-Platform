# 丹智慧眼 —— 基于AI与大数据的丹阳眼镜产业智能化平台

> 南京师范大学中北学院 大学生创新创业训练计划项目

---

## 一、项目背景

丹阳作为"中国眼镜之都"，眼镜年产量占全国 70% 以上，拥有完整的产业链。然而传统眼镜零售存在以下痛点：

- **选购效率低**：消费者需到店逐一试戴，耗时耗力
- **推荐缺乏个性化**：依赖店员经验，难以精准匹配用户脸型与需求
- **产业数字化程度低**：多数企业尚未利用AI技术赋能营销与决策

本项目旨在构建一个基于人工智能与大数据的眼镜产业智能化识别与精准营销平台，解决上述行业痛点。

---

## 二、项目目标

| 目标 | 说明 |
|------|------|
| 智能脸型识别 | 基于深度学习实现用户脸型自动分类（圆形脸、方形脸、鹅蛋脸、长方形脸） |
| 个性化推荐 | 结合脸型、瞳距、角膜曲率、近视度数等多维数据，智能推荐最匹配的眼镜 |
| 虚拟试戴 | 在线预览眼镜佩戴效果，降低决策成本 |
| 精准营销 | 积累用户数据，为企业提供消费者画像与营销洞察 |

## 四、核心功能模块

### 4.1 脸型识别模块

- 采用 **MTCNN** 进行人脸检测与对齐，将人脸区域裁剪为 160×160 像素
- 使用自研 **CNN 卷积神经网络** 进行脸型四分类（圆形/方形/鹅蛋脸/长方形脸）
- 模型结构：2层卷积 + 2层池化 + 全连接层，参数量约 80K
- 支持 GPU 加速推理

### 4.2 智能推荐模块

- 输入特征：瞳距、角膜曲率、近视度数
- 基于 **决策树分类器** 预测最适合的镜框形状
- 结合识别出的脸型与模型推荐结果，从眼镜数据库中匹配 Top-3 商品
- 返回眼镜详情：形状、材质、折射率、价格、图片

### 4.3 虚拟试戴模块

- 上传正脸照片后，前端 Canvas 将眼镜图片叠加至人脸上
- 根据人脸比例自动调整眼镜位置与大小
- 支持"换一款"功能，实时切换不同眼镜预览效果

### 4.4 数据管理模块

- 用户数据：瞳距、角膜曲率、近视度数，创建时间
- 眼镜数据：形状、尺寸、材质、度数范围、折射率、价格、图片URL
- 推荐记录：用户ID、推荐眼镜列表、识别脸型、时间戳
- 支持从 CSV 批量导入眼镜数据

## 五、创新点

1. **多维度特征融合**：将人脸视觉特征（脸型）与验光参数（瞳距、曲率、度数）联合建模，实现更精准的个性化推荐

2. **微服务架构**：Backend（Flask）与 Model API（FastAPI）分离部署，模型服务可独立扩展与更新，互不影响

3. **端到端闭环**：从用户拍照 → 脸型识别 → 智能推荐 → 虚拟试戴 → 详情查看，形成完整的选购闭环

4. **产业赋能**：平台沉淀的用户偏好数据可反哺眼镜企业，指导产品设计与精准营销策略

## 七、项目展望

1. **引入更多脸型类别**：心形脸、菱形脸等更细粒度分类
2. **AR 实时试戴**：基于 WebRTC 和 Face Mesh 实现摄像头实时虚拟试戴
3. **推荐算法升级**：引入协同过滤、深度学习推荐模型，结合用户行为数据
4. **小程序化**：开发微信小程序版本，降低用户使用门槛
5. **企业SaaS化**：为丹阳本地眼镜企业提供数据分析与精准营销SaaS服务
6. **移动端适配**：优化响应式设计，提升手机端体验
